# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, welcome newcomers, and keep discussions focused on the work. Harassment, discrimination or personal attacks are not tolerated.

Reports: open a private security advisory on GitHub or contact the maintainers through the repository. Reports are handled confidentially.
